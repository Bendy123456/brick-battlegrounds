# BRICK BATTLEGROUNDS v0.4

Browser 3D fighting game, based on the working v0.3 combat.

## Upgrades
- Nine fighters, 3×3 selectable roster
- More detailed minifigure-inspired ninja armor and proportions
- Tiled dojo, ornamental gates, lanterns and central emblem
- Adaptive third-person camera and basic reaction poses
- Fullscreen toggle and FPS monitor retained
- Fix: menu initialization now takes place after `ws` declaration, preventing the crash

## Update GitHub
Upload **contents** of this zip at the root of your existing repository, preserving `public/`. Commit to `main`, wait for Render auto deploy, then hard-refresh.

## Testing
Fight the bot, try all 9 characters, test round completion, fullscreen and controller. Test multiplayer separately. Target 60 FPS but monitor actual counter. Original game assets and code are not used.
